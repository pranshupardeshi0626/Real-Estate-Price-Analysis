🏠 MagicBricks EDA Project

🚀 Exploratory Data Analysis (EDA) project on real estate data scraped from MagicBricks.

📌 Project Overview

This project focuses on analyzing property listings to understand trends in pricing, property types, and housing patterns.

🎯 Objective
      1.Analyze property price distribution
      2.Identify common BHK configurations
      3.Understand property type trends
      4.Explore relationships between available features
      

🛠️ Tech Stack

      🐍 Python
      📊 Pandas & NumPy
      📉 Matplotlib
      🎨 Seaborn
      🌐 BeautifulSoup / Requests
      

📂 Dataset Features

      Property Price
      BHK (Bedrooms)
      Property Type
      Basic Listing Details

🔍 Analysis Performed
      
      🔹 Univariate Analysis
          Price distribution
          BHK count distribution
          Property type frequency


      🔹 Bivariate Analysis
          BHK vs Price
          Property Type vs Price


      🔹 Multivariate Analysis
          Correlation heatmap
          Pairplot for numerical features


📈 Key Insights

      1. Most properties fall within a specific price range
      2. 2 BHK and 3 BHK are the most common configurations
      3. Certain property types are more frequent in listings
      4. Price shows variation based on BHK configuration
